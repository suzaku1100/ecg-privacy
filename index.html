プライバシーポリシー / Privacy Policy

日本語

本アプリ「心電図トレーニング」（以下「本アプリ」）は、利用者のプライバシーを尊重します。

  • 収集する情報: 本アプリは、氏名・メールアドレス・位置情報・連絡先などの個人情報を一切収集しません。アカウント登録も不要です。
  • 保存されるデータ: 学習の進捗（解答履歴・成績・間違いキュー・設定）は、利用者の端末内にのみ保存されます。これらのデータが端末外へ送信されることはありません。
  • 第三者への提供・トラッキング: 本アプリは解析ツールや広告を使用せず、いかなる第三者にもデータを提供しません。利用者の行動をトラッキングしません。
  • ネットワーク通信: 本アプリは学習機能の利用にあたりネットワーク通信を必要としません（完全オフライン動作）。
  • データの削除: 設定画面の「学習データを消去」から、端末内の全データをいつでも削除できます。
  • 医療上の注意: 本アプリは教育目的の学習アプリであり、実際の診断・治療には使用できません。表示される心電図は合成された架空の波形です。

お問い合わせ先: nurseworks.info@gmail.com

English

This app ("ECG Training") respects user privacy.

  • Data collected: The app collects no personal information (no name, email, location, or contacts). No account is required.
  • Stored data: Learning progress (answer history, scores, review queue, settings) is stored only on the user's device and is never transmitted off-device.
  • Third parties / tracking: The app uses no analytics or advertising SDKs, shares no data with third parties, and does not track users.
  • Network: The app requires no network connectivity for its learning features (fully offline).
  • Deletion: All on-device data can be erased anytime via "Erase learning data" in Settings.
  • Medical notice: This is an educational study app and must not be used for actual diagnosis or treatment. All displayed ECGs are synthetic, fictional waveforms.
